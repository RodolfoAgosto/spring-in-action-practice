# Spring in Action Labs — Learning Journey

This repository documents my practical learning journey in the **Spring Framework** ecosystem, based on the book *Spring in Action (6th Edition)* by Craig Walls.
The goal is to master modern backend development with Spring Framework.

---

## Overview

Each module within this repository represents a section or chapter of the book, implemented from the ground up with a didactic and professional approach.

In addition to the examples from the book, I include enhancements, experiments, and documentation to reinforce understanding of each topic.
